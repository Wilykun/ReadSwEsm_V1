1. *.iqc — iPhone Quoted Chat*
   • Ketik `.iqc <teks>` → langsung jadi gambar screenshot ala iPhone.
   • `.iqc` tanpa teks → ambil pesan terakhir di chat (teks/sticker) atau quote acak.
   • Reply pesan teks/sticker lalu `.iqc` → screenshot dari pesan itu.
   • Pakai library `iqc-canvas` (Hann Universe): bar reaksi emoji warna, menu Beri Bintang/Balas/Teruskan/Salin.
> _Hasil: screenshot chat ala iPhone langsung dari bot, akurat._

2. *.stickerai — Sticker dari Prompt AI*
   • Ketik `.stickerai <prompt>` → bot buat gambar AI (model flux via Pollinations, tanpa API key) lalu otomatis jadi sticker die-cut gaya chibi/anime.
   • Alias: `.aisticker`, `.aistiker`, `.stikerai`. Brand pack/author mengikuti `config.json` seperti `.sticker`.
   • Prompt dibungkus blok negatif eksplisit (tanpa teks/logo/watermark/tangan) + gambar di-crop tengah 86% sebelum konversi — hasil bersih dari teks acak & watermark palsu yang kadang digambar model.
   • Reaksi proses ⏳/✅/❌ seperti `.sticker`, timeout generate 120 detik + retry 1x dengan seed baru bila gagal.
> _Hasil: sticker AI custom dari teks prompt, bersih dan siap pakai._

> _Hasil: sticker di dalam paket tampil normal dan paket terkirim utuh sebagai 1 paket, tidak lagi pecah satuan karena gangguan jaringan sesaat._

6. *.stickerly/.stickerpack — Pencarian Realtime, Pilihan Paket & Pengalaman Pakai*
   • Pencarian realtime ke Stickerly (semua bahasa, semua jenis sticker): `.stickerly <keyword>` sekarang tampilkan daftar *30 paket* — balas pesan daftarnya dengan angka buat memilih, atau ketik `batal`.
   • Info tiap paket lengkap: nama, kreator + username, pengikut kreator, kode paket, jumlah sticker, views, download/export, dan link paket. Pesan sukses juga memuat info realtime penuh yang sama — sekali lihat langsung tahu paket apa yang disimpan dan sepopuler apa.
   • Paket dikirim sebagai *1 paket native* berisi semua sticker (fallback kirim satuan bila paket gagal total).
   • Semua sticker di paket otomatis memakai pack/author dari `config.json` (`"sticker": { "pack", "author" }`) — mengikuti config seperti `.sticker`/`.wm`, tanpa re-encode (animasi utuh).
   • Loading *persen asli* dari jumlah sticker yang benar-benar selesai diunduh/dikirim (sebelumnya bar animasi berbasis waktu yang berhenti di tengah), menyatu di *1 pesan* yang di-edit dari info → persen → kirim paket → selesai, tanpa pesan berserakan.
   • Penjaga anti dobel: paket yang sama di chat yang sama tidak bisa diproses dua kali bersamaan — perintah kedua dijawab sopan, bukan membuat pesan tumpuk.
   • Pesan daftar pilihan *langsung berubah jadi loading* begitu user membalas angka — daftar tidak tertinggal di chat (bila edit ditolak WhatsApp, bot otomatis kembali memakai pesan status baru).
   • Tampilan balasan tanpa garis kotak: formatting WhatsApp native (tebal, miring, kode, daftar bernomor/berpoint, kutip) sesuai konteks.
> _Hasil: cari, pilih, dan simpan paket Stickerly utuh langsung dari chat — realtime seperti aplikasi aslinya, rapi tanpa spam._

7. *.fb / .ig / .tt — Caption Full AI (Gemini API Resmi)*
   • Vision & caption sekarang memakai *Gemini API resmi* — API key disimpan di `config.json` (`"geminiApiKey"`), dibaca segar tiap panggilan sehingga ganti key langsung berlaku tanpa restart. Jalur lama (scraper) menjadi fallback.
   • Analisis konten naik kelas: bukan cuma thumbnail — bot mengunduh video (maks 45MB) dan menganalisis *5 frame* dari awal sampai akhir video, jadi caption menggambarkan isi video yang sebenarnya.
   • Sebelumnya jalur vision lama mati diam-diam (auth scraper kedaluwarsa) sehingga caption hanya dari metadata + formatting kadang rusak — sekarang caption full AI dengan formatting WhatsApp native yang bersih.
> _Hasil: caption `.fb`, `.ig`, `.tt` akurat sesuai isi video, bukan tebakan dari sampul._
